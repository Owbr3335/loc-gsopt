# Demo country boundaries

Natural Earth Admin 0 Countries, 1:110 million. Downloaded 2026-09-13 from:
https://naturalearth.s3.amazonaws.com/110m_cultural/ne_110m_admin_0_countries.zip

Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/
Original accompanying README and version metadata are retained.
The demo uses ADM0_A3 codes. These coarse polygons are for exploratory placement;
country assignment follows this dataset, including its territorial conventions.
They do not establish precise legal boundaries or site suitability.
